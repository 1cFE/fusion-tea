Description

The zip file from this repository contains all the data and scripts from the paper 'Efficient Computation of Stellarator Coils with an Augmented Lagrangian
Optimization Method', currently available in https://arxiv.org/abs/2507.12681. At the present time, in order to be able run the scripts it is necessary to import simsopt and clone the repository present in https://github.com/PedroFranciscoGil/simsopt/tree/auglag_coils.
