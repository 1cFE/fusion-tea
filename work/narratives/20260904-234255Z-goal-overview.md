# Goal overview: the seven maturation goals at a glance

This is an owner-facing summary table built from the seven narrative snapshots in this folder. It is not evidence, state, or a decision record. If a cell and a cited narrative or goal record disagree, the record wins.

The Question column says whether the goal answered what it set out to ask. The Model changed and What got better columns say whether the model got better. These are independent. A goal can improve the model and still not answer its question, and a goal can answer its question without touching the model.

The wall-and-heating row reflects the goal trail and Git state at the time of writing, which is later than that goal's narrative snapshot. Its second-round model change (WI-041) has landed and its second-round sweep has run and been committed. The review of that round is the next step.

## Reading the table

- Every goal that changed the model made it more realistic, whatever the Question column says. The three goals with no model change either corrected an input, measured what a correction did, or produced facts the next goal needed.
- Making the model more realistic did not make its numbers agree more with the paper. Across these goals the reference design's cost went from 275 to 313.5 $/MWh, and it now fails two of the model's nine checks. That is the model getting more honest, not drifting. Each time a typed-in number was replaced by a calculation, the calculation was set up to reproduce the paper's input values, and the model's outputs were left free to disagree.
