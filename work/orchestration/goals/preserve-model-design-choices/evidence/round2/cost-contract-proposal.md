## Authority and recommendation

[OWNER-VERBATIM] MR-7 records: “As soon as you start introducing ‘sizing’, then you are basically pre-defining which design parameters are ‘free’ and which are ‘derived’. this is explicitly what we wanted to avoid.” [OWNER] `../round2-owner-extension.md` makes residual demand-priced equipment and missing capability checks required repairs. All contract choices below are [AGENT] interpretations; none is an owner-originated settled choice.

Use three explicit contracts: geometry-priced material with a selected procurement duty class; equipment priced against a supplied rating when the inherited price basis actually matches that rating; and selected package amounts whose price basis has no demonstrated physical-rating interpretation. Keep operating fuel, energy and replacement frequency demand-responsive. Do not change the physical power balance to force a price basis to match it. The package-amount mechanism below supersedes direct class-driven evaluation for independently rated packages whose full specification is not priced by the inherited law.

A procurement duty class is a selected description of the purchased design used by a conditional price proxy. It is never a demonstrated capacity. Associate it with the same component that owns supplied equipment and any independent performance check. For example, the heat-rejection package owns both a selected total-thermal plant class used by the inherited price law and a rejected-heat rating used by the physical check. Their association is a declared package assumption. No model equation establishes a conversion between those quantities.

This repairs purchase inflation with demand; it does not make the inherited costs engineering quotations. If a reviewed task requires a validated price-versus-physical-rating relationship for a package lacking one, these proxy contracts are insufficient. The alternative is a supplied package quote with its equipment scope and ratings declared together. Do not invent a conversion or hide the gap behind a price multiplier.
