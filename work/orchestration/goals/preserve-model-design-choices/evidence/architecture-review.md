## Consequential findings and implementable contract

1. **Fix all hardware consumers, not just public field names.** For magnet evaluation, supply pack side [m], installed reference turns [1], operating turn current [A], existing shape/composition, support total mass [kg] and per-coil casing mass [kg]. Compute ampere-turns as turns times current and conductor length as coil count times installed turns times existing set factor times circumference. Use selected side for volume, fit, stress, insulation and cryogenic envelope; use selected masses for cost and cryogenic support loads. Density becomes a diagnostic. Preserve existing set/reference corrections and empirical conductor refusal. Retain current-density and field inversion only as explicit construction/operating analyses that produce an independently evaluable design. This uses existing identities; discrete windings and arbitrary shapes are unnecessary for this bounded repair.

2. **Facilities need supplied geometry and segmentation.** Existing four-wing topology can remain an explicit scenario restriction without owner ceremony. Supply clear room dimensions, relevant route/partition dimensions, parcel bounds and storage offers; derive civil quantities from those supplied values. Compare required envelopes/positions against them. Preserve placements only as a declared fixed layout contract, with containment/overlap checks. `vessel_schedule()` also chooses blanket package count by ceiling volume/capacity: expose selected package count plus material-capacity margin or retain a separately identified packaging proposal. Freezing only outer dimensions misses this installed-inventory choice. Small geometrically meaningful insufficient rooms must produce fit failure before civil arithmetic would produce invalid wall volumes.

3. **Fuel processing is the smallest complete capacity repair.** Replace `processing_capacity_margin` in the active physical path with supplied per-module D+T capacity [kg/s]. Bind this to cost scaling and exposed equipment capacity. Keep running `dt_processing_flow` separate; compare per-module quantities or multiply both sides by module count. Preserve `source_conditions` as cost-support status, never adequacy. Existing cost algebra already scales a capacity quantity; this change needs no new empirical law. Migration must identify the removed public control. Reserve and buffer masses can likewise be supplied and compared against existing coverage requirements, with actual maintained stocks driving decay; this requires an explicit contract, not new tank physics.

4. **Cooling price separation is possible now; pump qualification is not.** The executable at `generated/handwritten/mfe_cooling_equipment/cooling_equipment_impl.py:49` explicitly prices helium pumping shaft duty at suction pressure, not motor nameplate. Salt pricing at `:84–93` uses volumetric flow, head and electrical motor hp. Supply a separate declared design operating point, retain these meanings and efficiency consistency, and route its prices into purchase, spares, replacement and shipping accounts. Keep actual operating heat/flow/work on the energy path. A design point can be held fixed and conditionally priced with unchanged correlations. Scalar power/flow/head comparisons do not establish a feasible pump envelope. Report them as screens with qualification unavailable; do not manufacture a sufficient-pump pass. A pump/compressor map or explicitly adopted approximation is a scientific gate only for the stronger adequacy claim.

5. **Preserve model anchors independently of selected hardware.** Split primary hydraulic reference flow from supplied circuit rating (`mfe_primary_loop.sysml:93`). If exchanger geometry is later opened, detach reference U calibration from selected area: the executable currently computes U using its fixed area. Geometry/mass/void/facility consistency and altered hydraulics then need review. Keeping the current declared geometry family is an implementable limited contract.
