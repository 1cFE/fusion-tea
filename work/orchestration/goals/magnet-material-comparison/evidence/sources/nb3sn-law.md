# Evidence note: Nb₃Sn strand critical-current law (nb3sn-law)

Request `knowledge/research/requests/REQ-MMC-NB3SN-LAW-01.json`, run `knowledge/research/requests/runs/REQ-MMC-NB3SN-LAW-01/20260929T230024793397/`, return class `REGISTERED`.

Bottom line: three open primary sources are registered. The best fit for the comparison is Tsui and Hampshire (2012). It prints the ITER scaling-law form (the Bottura form) with all nine fitted parameters for two Bruker EAS bronze-route ITER TF strands and one OST internal-tin strand, at 10 µV/m (0.1 µV/cm), measured 4.2 to 12 K and up to 14.5 T. It also prints a refit restricted to 10–14 T and 4.2/8 K. Every parameter set in the three sources is either engineering Jc (whole-strand area) at 0.1 µV/cm, or non-Cu at a nonstandard 5 µV/cm criterion. No source gives a non-Cu, 0.1 µV/cm set for an ITER TF strand. The Bottura–Bordini ITER production parameterization and the NIST extrapolative scaling expression could not be captured. Both are queued for the owner.

Captured from the Durham superconductivity group site (URL in SOURCE_INDEX). It is the IOP publisher PDF with an IOPscience download cover as PDF page 1, so printed page N is PDF page N+1. Primary measurement paper on three advanced ITER internal-tin strands (OST, OKSC, OCSI), with Durham-law and "proposed ITER" parameter sets.

## Equations

- **ITER form (Tsui eq. 6–7; Lu eq. 11).** Jc(B,T,εI) = (C/B)·s(εI)·(1−t^1.52)·(1−t²)·b^p·(1−b)^q. Here t = T/Tc*(ε) and b = B/Bc2*(T,ε), with Tc*(ε) = Tc*(0)·s(ε)^(1/3) and Bc2*(T,ε) = Bc2*(0,0)·s(ε)·(1−t^1.52). The strain function s(εI) is Tsui eq. (7), given in the table above. Both papers cite the form to Bottura 2008, "ITER TF Conductor Procurement Package 1.1.P6A" (Tsui ref. [16], output.md:365; Lu ref. [19], output.md:316). That is an ITER internal document and was not captured.
- **Current-density basis.** In both Durham papers, Jc and therefore C are engineering values: critical current over the whole strand cross-section (Cu plus non-Cu). Tsui prints C in A T m⁻². Lu prints C with no unit. The whole-strand basis is stated in the text, but the unit is not confirmed. Godeke's C1 is per non-Cu area.
- **Sign ambiguity in εM (for the checker).** The εM entries use different signs across the sources:
    - Tsui's Durham law (eq. 5, p.6) uses εI = εA − εM, with εM the applied strain at the Jc peak. Tsui Table 4 gives OST εM = +0.254 %.
    - Tsui's ITER Tables 5 and 8 print negative εM (OST −0.284 %).
    - Lu's ITER Tables 9–11 print positive εM (OST 0.1341 %).
    - Godeke eq. (22) uses εa = εapplied + εm, with εm the negative pre-compression.

  Neither Durham paper prints the εA-to-εI relation used inside the ITER fit. Tsui notes that "the ITER parameterization generally overestimates the value of εM" (output.md:241). A checker must fix the convention before evaluating either table against the paper's figures.
- **Possible repeat in Tsui Table 8(a).** The OST row of Table 8 repeats ε0,a, εM, Bc2*(0,0) and Tc*(0) from Table 5(a) exactly (0.207, −0.284, 32.59 T, 16.26 K). Only p, q, C, Ca1 and Ca2 change. The paper does not say whether those four were held fixed in the reduced refit or copied in error. The BEAS rows change all nine.
- **Godeke C1 unit.** Table 1 prints C1 = 46.3 with no unit. The Jc(H,T) fit on p.22 prints C1 = 42.8×10⁹ AT/m² in the same notation, which suggests 10⁹ A T m⁻² (non-Cu). This is not stated for Table 1. Treat it as a bounded assumption until checked.
- **Naming.** Lu labels the parameters Bc20max*(0,0) and Tc0max*(0) (ITER naming). Tsui labels them Bc2*(0,0) and Tc*(0). Godeke uses μ0Hc2m*(0), Tcm*(0), and C1 in place of C.

## Gaps

- **Bottura–Bordini ITER production parameterization not captured.** This is the reference parameter set fitted across ITER TF production strands. Without it, the comparison can cite only single-sample, qualification-era strands (Tsui BEAS and OST, Lu advanced internal-tin). It cannot claim an "ITER TF production-average" strand law.
- **NIST extrapolative scaling expression not captured.** The NIST page gives only the abstract. The full paper (IEEE TAS 2017, doi:10.1109/TASC.2017.2647852) is paywalled. Triage of the abstract page only: it is a method for extrapolating full Ic(B,T,ε) matrices from limited data, and it names no fusion-strand parameter set. So it is a method to evaluate against the ITER form, not a drop-in parameter source. It was not adopted and is not evidence here.
- **No non-Cu set at 0.1 µV/cm for an ITER TF strand.** The Durham sets are engineering Jc. Converting them to non-Cu needs each sample's measured Cu/non-Cu ratio, which neither paper prints. Tsui gives only the ITER spec, 1.0 ± 0.1. Lu gives nominal ratios. A conversion would be a bounded assumption. Godeke's non-Cu set is at 5 µV/cm, so it is not comparable to a 0.1 µV/cm criterion without a stated n-value correction.
- **No EU DEMO-class strand law.** None was found within this run's search budget. The one EUROfusion document triaged (Bruzzone et al., CP(15)09/01) is conductor-level and prints no strand law.
- **Temperature coverage.** No measured points lie between 4.2 K and 8 K in Tsui, so 4.5 K is interpolation within the fit. Lu includes 6 K data, but for internal-tin strands only.
- **Field coverage.** The ITER TF bronze strands (BEAS) were measured to 14.5 T. For them, anything above 14.5 T is extrapolation. Lu's internal-tin strands go to 28 T.
- **Self-field.** Lu states that no self-field correction is applied (output.md:69). Tsui does not say.
- **What the comparison can claim.** A sourced Jc(B,T,ε) for named ITER TF-class strands, on an engineering basis at 0.1 µV/cm, inside 8–14.5 T and 4.2–12 K. It cannot claim a non-Cu or production-average value, or a validated extrapolation beyond the measured domain. It cannot evaluate the ITER-form strain term until the εM convention is resolved.
