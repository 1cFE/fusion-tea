# Equipment and cost binding audit of the 891 MW alternative (T-002)

**Scope**: stored case `resized-compressor-1700-network-scaledflows-0.85` (alternative, 891.002 MW net) against `nominal-calculated` (baseline, 423.107 MW net). All money is USD2004 as the ledger declares (`cost_ledger.evaluate.currency_year_in = 2004`). Bindings were read from `models/designs/aries_cs_integrated/plant.sysml`, laws from `models/library/analyses/integrated_equipment_costs.sysml`, `integrated_lifecycle_costs.sysml` and the native completions under `exploration/aries_integrated/native_completions/`. Values are from the two `cases.json` files named in the brief; the package was not executed. Where a third case is cited, `alt2` means `resized-compressor-1700-network-0.85` (same alternative with the primary flows left at 3261/26860/283 kg/s).

**Path note**: the brief's `evidence/financial-handoff.md` is not in this goal's evidence directory. The only file of that name is `work/completed/20260922_WI-090_aries-integrated-equipment-and-costs/evidence/financial-handoff.md`; only its § "Purchased ratings and actual demands" and § "Capital leaves and exact price-factor controls" were read.

**Grades** follow the brief: *supported* = a source amount or reviewed law applies to this configuration; *assumed* = an agent law or allowance applies with a declared range; *unresolved* = a changed input moves the item's duty and nothing in the bindings responds, or the basis does not apply. I applied one judgment the brief leaves open: a fixed allowance whose duty moved by a few percent (primary flows +3 %) stays *assumed*; one whose duty moved by tens of percent or more with no declared applicability (cycle flow +21 %, recuperator duty 2.2x) is *unresolved*.

## Inconsistencies and proposed smallest corrections

None of these are applied. Each names the binding, what is inconsistent, the smallest correction, and the numerical effect where the stored outputs allow it.

1. **Recuperator at 0.95 effectiveness has no equipment representation.** Binding: `plant.sysml` part `cycle` (`recuperator_effectiveness`) consumed by `heat_exchangers.evaluate.recuperator_effectiveness_in` and `recuperator.evaluate.effectiveness_in`; cost only through the fixed `conversion_services` allowance. Inconsistent: a chosen operating characteristic that adds 960 MW of recovered heat changes no purchase, has no rating and no screen, while every other cycle machine has a rating and a screen. Smallest correction: declare a `recuperator_capacity.selected_rating` (MW recovered heat) with an `Offered Capacity Screen` on `recuperator.recovered_heat`, and carve a `recuperator_equipment` selected-inventory leaf out of the 20 % conversion allowance with a declared reference quantity. Numerical effect: not computable from the stored outputs; a linear law referenced to the baseline's 795 MW would put this case at ratio 2.21, outside the [0.5, 1.5] extrapolation band. If the owner prefers not to represent it, the case record should state that the 891 MW result assumes a recuperator that is not purchased.

2. **Cycle-side allowances do not respond to 1700 kg/s.** Bindings: parts `conversion_services` and `secondary_transport`, both `Scaled Amount` -> `Supplied Purchase Cost` with `selected_quantity` 1. Inconsistent: intercooler duty rose 21 % and no output evaluates the coolers or the cycle-side transport. Smallest correction: declare an applicability statement for the two fixed packages against `cycle.selected_flow` (either "fixed for cycle flow ratio up to X" in the design register, or a `cycle_flow_capacity.selected_rating` screen). Numerical effect: 0 on cost as currently declared.

3. **Divertor pump fixed power 27 MW has no basis and contradicts its own proxy.** Binding: part `divertor_pump`, `pump_mode` 1, `fixed_power` 27 -> `evaluate.electric` -> `deposition.divertor_pump`. Inconsistent: 13.6x the mode-0 proxy at 291.5 kg/s (1.98 MW) and 2.7x the 10 MW reference at 500 kg/s; the purchased pump has a flow capacity but no power rating, so nothing checks it. Smallest correction: record the source of 27 MW in the case or the design register; if none exists, present mode 0 as a separately declared alternative. Numerical effect: the auxiliary draw differs by 25.0 MW (90 % of which returns as divertor-loop heat), so the net-electric effect is bounded by 25 MW and cannot be resolved without execution.

4. **Helium and PbLi pump purchases are demand-matched at zero margin.** Bindings: parts `he_pump` and `pbli_pump`, `selected_flow_capacity` set equal to `heat_exchangers.he_flow` / `.pbli_flow` by input (screen margin 0.0 in both cases). Inconsistent only in disclosure: MR-7 allows a demand-matched purchase but requires it to be disclosed as such. Smallest correction: state in the case record that 3359 and 27666 kg/s were chosen to equal the operating flows. Numerical effect: alt vs alt2 shows the whole flow-scaling purchase is +1,168,372 direct and +0.019 /MWh LCOE; the scaling's real effect is thermal (PbLi hot-bound margin 4.408 -> 11.924 K).

5. **Auxiliary itemization collapsed with no recorded basis.** Binding: part `generator_auxiliaries` inputs. Inconsistent: fuel-processing electric set to 0 while exhaust rate rose 33 % and the processing equipment stays purchased; cryo halved; a 50 MW "other" lump replaces the items. Smallest correction: record the basis for each of the five values (or the single lump) in the case record. Numerical effect: 0 on capital; 28.8 MW more dissipated auxiliary than the baseline.

6. **PbLi pump reference power 0.01 MW.** Binding: part `pbli_pump`, `reference_power`. Inconsistent with E3's own statement that PbLi MHD pumping needs a hydraulic model; the value is placeholder-scale and carried unchanged. Smallest correction: mark the value as a declared placeholder in the design register or supply a basis. Numerical effect: 0.011 MW in this case; a realistic value would be an auxiliary load of a different order, which I cannot estimate without price or hydraulic research (excluded).

Disclosures that are not binding errors: the three duty packages price at different USD/MW because the 25 % bucket is split equally (declared agent allocation); the replacement cadence does not see the 33 % neutron-power increase (selected life); the O&M binding uses literal 1000 MW rather than `plant_ledger.net_electric` (deliberate fixed allowance); the compressor margin is 1.9 % (thin, but satisfied by an explicitly declared purchase).

## Missing evidence

- `Supplied Purchase Cost` and `Offered Capacity Screen` calc definitions are in library files the brief did not name. Behavior was inferred from outputs: cost = budget x `selected_quantity`; margin = rating - demand; satisfied at margin >= 0 (pump screens report satisfied at exactly 0.0).
- `Annual OM Cost` definition not in the named files; behavior inferred from the literal bindings and the unchanged 70 M output.
- Basis for the changed auxiliary inputs (`he_pump.fixed_power` 170, `divertor_pump.fixed_power` 27, cryo 5, control 0, fuel 0, other 50 MW) and for `deposition` radiation/exchange fractions: absent from every named file; the brief supplies the values only.
- Basis for `pbli_pump.reference_power` 0.01 MW and `he_pump.reference_power` 156 MW: not in the named files (E3 declares the proxy, not the references).
- `source-basis.md` (Lyon Table III transcription) was not named; source amounts were taken as transcribed in the WI-090 design § account map.
- No declared applicability range (in flow, effectiveness or rating) for the fixed packages `conversion_services`, `secondary_transport`, `primary_piping`, `electrical_equipment`; E4 gives price-factor ranges only.
- No declared reference geometry or cost for the recuperator; the 20 % conversion bucket is not split between recuperator and services.
- `financial-handoff.md` resolved to the WI-090 completed directory (see path note); the goal's own evidence directory has no copy.
