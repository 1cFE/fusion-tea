## Shapes that were refused, and the rule each teaches

- Rewriting the EXPOSE binding line itself to read the EXPOSE (`:>> B_peak = magnet.B_peak`) — `SI_ALIAS_CYCLE`. An EXPOSE binds to the calc output; only *outside* consumers read the EXPOSE.
- A variant definition that retypes a sub-part (`part :>> winding_pack : 'NI Winding Pack'` inside the variant def) while the instance also redefines that sub-part — `SYSML_NAMESPACE_NOT_DISTINGUISHABLE` (member shadows the inherited redefinition). Retype the sub-part at one level only: the instance.
- An instance binding a variant sub-part's attribute without restating the sub-part's type — syside `No Feature named 'f_insulation'`. The instance restates the type on the nested redefinition.
- The instance must import the package that defines a variant it names (`private import mfe_power_core::*;`).
- A subtype cannot re-bind a template calc's formals nor a bound (`=`) EXPOSE, and a redefining calc usage matches parameters positionally (`redefinition_probe/README.md`, variants a–d). The overridable value is `default`: a swap seam is `attribute x : Real default <calc>.<out>;` on the base, rebound `:>>` by the variant (variants e, f; Stage E).
- From the grounding probe: `loop` is a reserved word; a def-level `attribute x : Real = v` is a binding a nested `:>>` cannot override — declare without a value; a conjugated port's item directions flip.
