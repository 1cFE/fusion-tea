**B2 — Finish the route and opening specification.** The final wall-expanded cross is a sensible correction to the zero-wall prototype. This is a conceptual swept-envelope check, not a request for transporter engineering or code-qualified fire separation.

**B3 — Remove quantity/accounting ambiguity.** Specify wing exterior-wall takeoff using interior width that includes partition thickness, then add partition solids once. The [CAS50 calculation](../../../models/library/analyses/mfe_account_costs.sysml:599) applies shipping to CAS20 **with contingency**, while the proposed exclusion is described as the installed subtotal.
