# Computed breeding integration design

[AGENT] Candidate interface design, before production edits. The transport method is independently prechecked; numerical table release remains pending. Reference requirements: spec.md. All choices below remain agent decisions, subject to evidence and independent interface review.

## Physical ownership

The blanket owns achieved breeding and its supported design choices. The stellarator instance specializes the generic blanket's existing `tbr` interface with a library calculation driven by breeder thickness at fixed 70% Li-6 atomic enrichment. Generic MFE consumers retain the existing `blanket.tbr` interface. A generic plant with no neutronics implementation does not acquire a claimed prediction by default.

The calculation also receives the geometry that determines its applicability: plasma major/minor radius and elongation, first-wall and vacuum-gap thickness, reflector, high-temperature shield, structural, assembly-gap and vessel thickness. These must match the transport table's fixed geometry. The represented material and source scenario is immutable table metadata; its reference temperature and fractions are not independent supported public levers. Unsupported geometry does not silently extrapolate. It produces an explicitly undefined carrier and fails applicability, preserving the other diagnostic plant outputs for failed study rows. Document the carrier so zero cannot be mistaken for predicted physical breeding.

The reusable transport interpolation definition lives in `models/library/analyses/mfe_tritium_breeding.sysml`; the stellarator owns its occurrence and EXPOSEs its outputs on the blanket. A typed handwritten implementation is acceptable for table lookup, finite/domain checks and uncertainty; its response data, full hashes and source/validation manifest ship with the generated package and participate in executable identity. The table is generated by physical transport, never assigned to selected design labels.

## Quantities and predicate

Publish achieved mean TBR, Monte Carlo standard error, interpolation error allowance, numerical lower estimate, applicability flag and separately calculated isotope contributions where supported by the table. The numerical lower estimate is not a physical confidence bound. Report physical sensitivities and unquantified bias through the immutable evidence/manifest; do not relabel their sum as independent Gaussian error.

Expose the existing fuel-balance required TBR through its owning fuel-cycle part. A small library adequacy calculation combines the unchanged design floor and the fuel requirement using their maximum, reports both margins and supplies the final comparison. Preserve the existing `tbr_ok` predicate identity if possible; extend its explicit operands to require valid applicability. It must fail for insufficient breeding, undefined results and a numerical margin crossing the requirement. This is a necessary conditional conceptual-design screen, not actual stellarator qualification.

Add production rate, extracted supply and balance diagnostics using the existing burn-rate normalization if not already present. Production equals achieved TBR times burn rate; extraction applies only to breeder supply; exhaust recycle loss is a separate stream. Decay and stock growth stay explicit inputs. Do not change fuel procurement cost semantics while fixing the physical adequacy comparison.

## Domain and numerical release

The proposed one-dimensional interpolation uses breeder thickness from 0.60 to 1.00 m at fixed 70% Li-6 enrichment. A measured 100,000-history pilot required 29 seconds of active transport on two threads. Restricting the executable to one lever reduces the table and independent validation workload without changing the blanket concept or fitting published TBR. The candidate numerical freeze uses nodes 0.60/0.70/0.80/0.90/1.00 m, withheld midpoints 0.65/0.75/0.85/0.95 m and off-centre points 0.625/0.925 m, all with independent seeds. Target Monte Carlo standard error is at most 0.002 TBR; the initial interpolation budget is at most 0.01 including the declared statistical comparison allowance. Tighten precision or grid spacing if the adequacy margin is below 0.02 or validation fails. The transport evidence records the exact freeze before execution. Physical benchmark comparison and model/scenario sensitivities remain separate from interpolation checks. Any table refinement must retain failures and use fresh withheld validation.

No previous model pass is an acceptance condition. Study cases span the supported domain and report blanket volume/cost, coil bore and dependent plant quantities alongside breeding, both thresholds and feasibility. Unsupported-geometry cases explicitly demonstrate rejection. Current package lineage is separately identified from the immutable r2 archive.
