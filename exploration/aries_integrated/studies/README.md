The route requires `interface.json`, which is deliberately absent until the generated interface exists and is reviewed. Its schema is `aries-study-interface/v1`, with three nonempty maps: `entry_keys` maps every qualified input field to its entry-channel name; `channels` maps report labels to generated output names; `constraints` maps exact emitted constraint IDs to source-local identities. The route compares the complete prepared entry map and the full constraint catalog to these maps. Every proposal must supply all entries; numeric outputs may retain nonfinite values as failure evidence, while missing/null/nonnumeric publications refuse.
