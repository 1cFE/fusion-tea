## Required correction R1

The new selected10 kg tritium stock drives annual decay, but the design says the existing fuel occurrence is reused unchanged. Its `I_total_in` still binds independent `dormant_inventory_atoms=0` (`models/designs/aries_cs_integrated/plant.sysml:126`). The reused definition computes `tbr_required` including `lambda_T*I_total` (`models/library/analyses/mfe_fuel_cycle.sysml:86`). Thus generated required-breeding demand would describe a different held stock from annual fuel demand. Only flow outputs are currently EXPOSEd, but that does not reconcile the generated calculation. Bind the same selected stock, converted kg→atoms using the existing tritium atomic mass, into the existing inventory input while retaining the calculation definition unchanged. Retire/migrate the independent dormant-stock entry and verify stock changes affect both decay terms without changing burn/exhaust. Alternatively justify and explicitly distinguish different physical stock boundaries. Coordinator identified this integration question; independent inspection confirms the missing binding.
