### F-1: Hypothesis 2 LCOE threshold contradicted by model output
- **Target:** Section 2 (Hypothesis 2) and model output
- **Finding:** Hypothesis 2 states "The concept achieves sub-$100/MWh LCOE only if capacity factor exceeds approximately 70–80%." The model output shows 640 $/MWh at 75% capacity factor. With a sensitivity elasticity of -0.96 on availability, even 90% CF yields ~533 $/MWh — still 5× above the claimed threshold. The claim frames capacity factor as the binding constraint for reaching $100/MWh, but the model's cost structure (C220103 = $6.9B magnets alone) makes that threshold unreachable through CF improvement alone. This is an internally inconsistent statement that would mislead anyone interpreting what the model implies about the technology's economics.
- **Recommendation:** Revise Hypothesis 2 to state the threshold correctly: that LCOE scales approximately inversely with CF (a 2× CF swing ≈ 2× LCOE swing), making CF the *dominant relative lever*, but that absolute competitiveness (sub-$100/MWh or comparable to grid alternatives) requires both high CF AND a multi-generation REBCO learning curve that is not captured in the current model. If a plausible "target scenario" LCOE exists (e.g., with $10/kA-m REBCO and 80% CF), state the assumed parameter values explicitly and note it as a scenario branch rather than a consequence of CF alone.
- **Priority:** blocking

### F-2: REBCO cost sensitivity sweep absent from model output
- **Target:** Section 2 (Challenge 1), Section 5 (Modeling Approach — primary scaling axes), and model output sensitivity table
- **Finding:** The analysis correctly identifies REBCO tape cost as the primary cost uncertainty, explicitly calling for a sensitivity sweep spanning "at least 5×" (Section 2) and "at least 10× the $10/kA-m commercial target" (Section 5). The model output's Key Assumptions section even states "Sensitivity sweep: vary C220103 by ±50% to bracket REBCO price uncertainty." But the sensitivity table in the model output only covers physical engineering parameters (availability, construction_time, eta_th, etc.) and interest rate — no C220103 cost sensitivity appears. The single most important cost uncertainty is documented but not executed in the output. Goal 4 (key hypotheses testable) and Goal 5 (risks captured as sensitivity parameters) are both compromised.
- **Recommendation:** Run and report the C220103 sensitivity sweep in the model output. The sweep should cover at minimum: current ARC-paper midpoint (baseline), ±50% of baseline, and the commercial-target scenario ($10/kA-m tape translated to a C220103 value). Report the LCOE at each point. If the sweep reveals a qualitative transition (e.g., below some C220103 value the concept reaches a breakeven threshold), note that inflection point explicitly.
- **Priority:** important

### F-3: I-mode fallback scenario absent from Section 5 parameter table
- **Target:** Section 5 (LCOE-Relevant Parameters) and Section 2 (Hypothesis 3)
- **Finding:** Hypothesis 3 is explicit: if I-mode is not achieved at ARC parameters and the plasma falls back to H-mode, net electric output drops from ~261 MWe to ~80–100 MWe with identical capital cost — a 2.5–3× increase in $/kWe. This is a discrete scenario branch, not a continuous parameter. But Section 5's parameter table has no entry for it — neither in Available Parameters nor in Missing Parameters. The consequence (capital cost per kWe triples) is large enough to affect the model's order-of-magnitude LCOE result, yet there is no mechanism to evaluate it from the model as specified. By contrast, the regulatory cost multiplier (also a discrete branch) is correctly flagged as a scenario parameter in the Modeling Approach subsection.
- **Recommendation:** Add an I-mode/H-mode scenario entry to the Section 5 Missing Parameters table (gap type: truly-unknown, criticality: important). State the key parameter consequence: net electric output drops to ~80–100 MWe (vs. 261 MWe baseline) with no change in capital cost, driving LCOE up by approximately 2.5–3× relative to the I-mode design point. Reference Hypothesis 3 and note that SPARC first plasma (expected 2027) is the near-term resolution event for this scenario branch.
- **Priority:** important
