### F-1: Base case design point is commercially non-viable by the analysis's own criterion
- **Target:** Model output header / H-2 scenario table
- **Category:** model
- **Finding:** The model base case (Qsci = 124, Q_wp = 8.7) is explicitly marked "NO (<10)" in the H-2 table — meaning the operating point used to produce the headline LCOE ($112.5/MWh) fails the commercial viability test the analysis itself defines. The XEC design target (Qsci ~250, Q_wp ~17.5) is cited in the Key Assumptions block as "XEC target ~250" but never appears as a model scenario. The analysis acknowledges the discrepancy ("Qsci is not a direct model input; it is inferred from the inverse power balance at the 400 MWe design point") but does not resolve it. A reader consulting the headline LCOE without reading the assumptions in depth will not understand that the base case is operating below the stated viability threshold.
- **Recommendation:** Add an explicit "XEC design point" row to H-2 at Qsci = 250 (η_laser = 7%) and report the implied net electrical output from the model's own power balance, along with the resulting LCOE. This anchors the headline number: if the XEC design claim is achievable, LCOE at Qsci = 250 is the optimistic ceiling; if the power balance implies Qsci = 124 at 400 MWe, that should be stated as the conservative operating assumption with the XEC claim flagged as requiring higher-than-modeled fusion yield or a different power balance framework. The base case should be the achievable design point, not a point the model marks non-viable.
- **Priority:** blocking

### F-2: plasma_t has high sensitivity elasticity but plasma-facing components are explicitly absent
- **Target:** Sensitivity table / model CAS structure
- **Category:** model
- **Finding:** `plasma_t` appears as the 3rd highest sensitivity lever (+0.22 elasticity) in the automated sweep, but Section 7 explicitly identifies "Plasma-facing components — absent, advantage" as a named differentiator from the tokamak reference. The magnet account (C220103) is correctly overridden to $0 for IFE, but there is no analogous treatment for `plasma_t`. A reader consulting the sensitivity table finds a high-leverage parameter that the analysis text says doesn't exist in this concept — creating a direct contradiction. Either `plasma_t` maps to a real cost component in the liquid-wall IFE geometry (FLiBe jet geometry? chamber shell thickness? nozzle cost?), or it is an MFE framework artifact with no IFE physical basis and should be overridden to zero with the corresponding cost reassigned to an appropriate account (e.g., CAS22 chamber/blanket structure).
- **Recommendation:** Identify what physical cost component `plasma_t` actually drives in the model for this concept. If it maps to FLiBe chamber geometry or nozzle/pump hardware, rename/document it accordingly in the Key Assumptions block. If it is an MFE-specific parameter with no IFE physical basis (analogous to the magnet account), override it to zero and explain this in the model output alongside the C220103 treatment. In either case, the sensitivity table should not show a high-elasticity parameter that contradicts the analysis narrative without explanation.
- **Priority:** important

### F-3: H-2 parameterizes P_net as input and derives Qsci as output — inverting the physics causal direction
- **Target:** H-2 scenario table / Section 2 modeling approach
- **Category:** model
- **Finding:** H-2 is framed as a "capsule gain floor" sensitivity analysis testing whether Xcimer can meet the Q_wp ≥ 10 viability criterion. But the table parameterizes net electrical output (P_net) as the independent variable and derives Qsci from the power balance — producing the counterintuitive result that higher P_net implies lower Qsci (150 MWe → Qsci 294; 400 MWe → Qsci 124; 500 MWe → Qsci 116). In IFE physics, Qsci is a property of target and driver design — it determines P_net, not the other way around. The H-2 parameterization answers "what Q_wp must be true to justify this plant size?" rather than "what P_net does a given capsule gain scenario actually produce?" These are different questions: the former is an economic break-even table; the latter is a design-point sensitivity analysis. The analysis text in Section 2 calls for H-2 to "vary the implied Qsci across the physically plausible range (100–300)" which is what the table does numerically, but the inverse physical relationship is not explained, making the directionality misleading.
- **Recommendation:** Add a note to the H-2 table clarifying the parameterization: "P_net is varied as an economic input; Qsci is back-derived from the power balance at each point. This is an economic break-even analysis — it identifies the minimum Qsci the concept must achieve to justify each plant size, not a projection of what each Qsci scenario delivers." Alternatively, implement H-2 as a forward physics table: fix Qsci at values across the plausible range (100, 150, 200, 250, 300), compute implied P_net and LCOE from each, and report whether Q_wp ≥ 10 is met. This forward direction maps directly to the physics uncertainty (will the target achieve Qsci = 250?) rather than the economic question (what Qsci is required?).
- **Priority:** important
