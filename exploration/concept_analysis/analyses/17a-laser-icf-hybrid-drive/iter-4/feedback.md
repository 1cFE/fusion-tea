### F-1: Testable hypothesis H-2 (capsule gain floor) is stated but not tested by the model
- **Target:** Section 2 (Testable Hypotheses) and model sensitivity output
- **Finding:** The analysis states H-2 as a testable proposition: "determine the minimum Qsci for wall-plug breakeven across the laser wall-plug efficiency range 5–7%." This is the right hypothesis given that capsule gain is identified as the #2 LCOE sensitivity parameter and the ⅔ power-law extrapolation is explicitly flagged as unvalidated above NIF scale. However, the model output tests H-1 (laser cost range), H-3 (thermal cycle), and H-4 (target fabrication threshold), but not H-2. The automated sensitivity table shows `plasma_t` (+0.20) as the closest proxy, but this is a wall thickness parameter, not capsule gain — no Qsci sweep or η_laser × Qsci grid appears in the model output. A reader following the analysis's guidance to "test H-2" would find no corresponding model scenario.
- **Recommendation:** Add an H-2 scenario table to the model output (or to the analysis's Modeling Approach section as a specification) that sweeps Qsci across the physically plausible range (100–300) at η_laser = 5% and 7%, reporting LCOE and recirculating power fraction at each point. At minimum, note which model parameter(s) correspond to Qsci variation so the reader can interpret the automated sensitivity table correctly.
- **Priority:** important

### F-2: Analysis states laser $/J is the #1 sensitivity lever but doesn't warn that it has zero gradient in the automated sweep
- **Target:** Section 2 (Modeling Approach, top sensitivities) and model sensitivity output
- **Finding:** The analysis identifies laser capital cost ($/J) as "the single dominant lever" for LCOE sensitivity — larger than any other cost driver. But in the model, the laser cost is implemented as a capital override (C220104 hardcoded at $700M), which the model output acknowledges gives "zero gradient by construction." A reader who reads the analysis's top-3 sensitivity ranking, then opens the model output's automated sensitivity table, will find laser cost entirely absent from that table and `availability` (-0.90) as the top engineering lever — the opposite ordering from the analysis narrative. Without explanation, this appears contradictory. The analysis's Modeling Approach section does not note that laser $/J sensitivity must be exercised through scenario branching rather than the automated sweep, nor does it explain why.
- **Recommendation:** In the Modeling Approach section, add a note under the top sensitivities that laser $/J cannot appear in the automated sensitivity sweep because laser cost is modeled as a direct override (not as a parameterized scaling variable), and that it is tested via the H-1 scenario table instead. This disambiguates the apparent conflict between "laser is #1 lever" and the model's sensitivity ranking.
- **Priority:** important

### F-3: Base LCOE excludes target fabrication cost with no explicit statement that it is a floor, not a realistic estimate
- **Target:** Section 2 (Challenge 6 — target cost), Section 5 (missing parameters), and model LCOE output
- **Finding:** The reported base LCOE ($115.8/MWh) excludes target fabrication costs entirely — the model output explicitly notes this cost "has NO analogue in MFE and is NOT in CAS70/80 defaults." The H-4 table shows that at the Goodin threshold of $2.5/target, target cost adds $11.2/MWh (~10% of base LCOE), and at $5/target adds $22.5/MWh. The analysis discusses the Goodin criterion in Section 2 and the gap table flags it as blocking. However, neither the analysis's Modeling Approach section nor the model output frames the $115.8/MWh figure as a pre-target-cost floor rather than a realistic LCOE estimate. For an IFE concept where target cost is explicitly identified as a blocking uncertainty with no published Xcimer value, presenting a single LCOE headline that omits this cost category without a clear "this is a lower bound" disclaimer risks misreading the economic viability case.
- **Recommendation:** In the Modeling Approach section, state explicitly that the LCOE model produces a floor estimate that excludes target fabrication cost, and that the realistic range is [base LCOE + $4.5/MWh] to [base LCOE + $22.5/MWh] depending on whether the Goodin threshold is met. Alternatively, adopt the Goodin midpoint ($2.5/target, adding $11.2/MWh) as the base-case target cost assumption to make the reported LCOE more representative. The H-4 table in the model output does the right work — the analysis narrative should refer to it as a required addendum to the headline LCOE figure.
- **Priority:** important
