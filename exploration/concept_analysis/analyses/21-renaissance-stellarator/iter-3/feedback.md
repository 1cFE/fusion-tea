### F-1: ISS04 ignition gap not framed as a cost scenario branch
- **Target:** Section 2 (Challenge #3) and Section 7 (cost model architecture recommendation)
- **Category:** analysis
- **Finding:** The model output quantifies that ISS04 extrapolation yields n·τ_E ≈ 2.7×10¹⁹ m⁻³·s at the published design parameters — roughly 11× below the Lawson ignition threshold at 10 keV across all rotational transform values tested (ī = 0.25–0.50). The analysis discusses the confinement uncertainty qualitatively in Challenge #3 ("enormous gap," "no experimental precedent") but does not trace the failure consequence into the cost model. The TEA implication of Q=∞ failing is substantial: C220104 (heating/CD), currently $0 because startup-only NNBI is assumed, would need to be replaced with a continuous steady-state heating system, and the machine size may need to grow if lower-Q operation requires more thermal power. The Q=∞ feature is listed in Section 7 as a novel cost advantage (eliminates heating capital, reduces recirculating load vs. ECRH stellarators), but no scenario quantifies what happens if this advantage is not realized. Goal 5 requires each technical bet to state the consequence if it fails; Goal 3 requires TEA implications to be called out. The "Q=∞ fails" branch is the most consequential single-point risk in the model and it has no TEA branch.
- **Recommendation:** Add a paragraph at the end of Challenge #3 explicitly framing the two-branch ignition scenario. Branch A (Q=∞ achieved): current model applies. Branch B (Q falls short of ignition): retrofit continuous heating system — estimate the capital cost of a continuous ECRH system for a stellarator of this scale (order of magnitude: $100–300M based on ITER ECRH or W7-X gyrotron program analogues) and add it to C220104; note that steady-state recirculating load increases by 50–150 MW. Update Section 7's cost model recommendation to include this as an explicit scenario branch alongside the coil cost and wall cost scenarios already identified. The model should report LCOE under both branches so that the Q=∞ cost advantage can be quantified, not just asserted.
- **Priority:** blocking

### F-2: Nearest-neighbor 36-helical-coil-stellarator absent from cross-concept comparison
- **Target:** Section 7 (cross-concept notes — divergences from peer stellarators)
- **Category:** analysis
- **Finding:** The analysis names three in-progress stellarators as comparators (09-qi-stellarator-hts, 20a-type-one-stellarator, 10-large-scale-stellarator) but omits concept 36-helical-coil-stellarator (Helical Fusion), which is a closer architectural peer for the two most novel differentiators. Concept 36 shares both the liquid metal wall (first-wall architecture) and sCO₂ power conversion with Renaissance Fusion — the only other concept in the survey to do so. The three named comparators all use contained solid blankets and steam or unspecified Rankine cycles; none share either the liquid-wall CAS structure or the sCO₂ BOP. The current comparison frames the liquid wall and sCO₂ cycle as features with no TEA analogue elsewhere in the survey, but concept 36 is a direct counterpart for both. Goal 1 (nearest-neighbor identification) and Goal 2 (novel vs. shared distinctions) are both underserved by this omission — including concept 36 would allow a side-by-side comparison on the two accounts (C220101 liquid wall cost, C240000 sCO₂ BOP cost) where independent modeling is required, and would reveal whether the two concepts make consistent assumptions.
- **Recommendation:** Add a paragraph in Section 7 comparing Renaissance Fusion to concept 36-helical-coil-stellarator (Helical Fusion). Address at minimum: (a) how the liquid metal wall architectures differ between the two (wall material, loading, flow geometry); (b) whether the sCO₂ cycle efficiency assumptions are consistent; (c) what cost model inputs can be shared between the two concepts and what must be built independently. Note concept 36 as a reference point for C220101 and C240000 cost estimates — even if its own parameters are uncertain, the comparison narrows the range of plausible values for both.
- **Priority:** important

### F-3: Liquid metal wall cost (C220101) has no scenario sweep despite x2–3 stated uncertainty
- **Target:** Model output — C220101 account and sensitivity section
- **Category:** model
- **Finding:** The analysis recommends "±50% uncertainty bounds" for C220101 (liquid metal wall system) and the model flags it as [UNCERTAIN x2–3]. However, C220101 is hardcoded at $400M with no parametric sweep — unlike C220103 (coil cost), which has a proper three-scenario branch (0.3×, 1.0×, 10×). A x2–3 uncertainty on $400M means the plausible range is $200M–$1200M, a $800M swing. At the model's scale (IDC ~$3B on a $10.85B/kW overnight), a $800M capital swing translates to a meaningful LCOE shift (~$15–25/MWh). The model's sensitivity table captures only the operating-side uncertainty (p_pump elasticity +0.058) but not the capital-cost uncertainty for the wall hardware itself. With two large independent uncertainties (coil cost and wall cost), the model currently shows asymmetric treatment: one swept, one not.
- **Recommendation:** Add a C220101 scenario sweep to the model output, mirroring the structure of the C220103 coil cost sweep: low (0.5×, $200M — Na-cooled fast reactor primary circuit lower bound, optimistic), mid (1.0×, $400M — current baseline), high (3.0×, $1200M — first-of-kind liquid metal fusion system premium). Report the LCOE range alongside the coil cost range so the two dominant architectural unknowns are both visible in the output and their combined uncertainty envelope can be estimated.
- **Priority:** important
