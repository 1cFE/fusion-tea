VERDICT: FINDINGS

### F-1: eta_th standardized upward from a small-plant-derated value, contradicting in-file rationale
- **Target:** `model_setup.py` line 89 (`eta_th=0.35, # standardized from 0.3`); related discussion in the docstring (lines 17–19) and `analysis.md` Section 2 (Power Conversion) / Section 5 (Parameters).
- **Category:** model
- **Finding:** The model sets `eta_th=0.35` with the comment "standardized from 0.3 per scoring_framework.md (Energy Capture: Thermal (unspecified))". This is the only framework-tracked concept where the standardization moves the value *upward* away from a physics/engineering-grounded estimate, and it directly contradicts the model's own rationale:
  1. **The docstring (lines 17–19) still asserts the deviated value**: `"eta_th=0.30 (conservative for small industrial 50 MW steam turbine)"`. The print block (line 273) also still prints "Thermal efficiency (eta_th=0.30)". Three places in the same file disagree on what the actual modeled value is, which is itself a code-quality concern.
  2. **The 0.30 rationale is a small-plant scaling argument, not a missing-data placeholder.** Industrial steam turbines in the 30–80 MWe class genuinely underperform 200+ MWe utility-scale plants by 3–7 percentage points (off-design exhaust losses, single-extraction reheat, no triple-pressure HRSG). The "Thermal (unspecified) → 0.35" canonical in `scoring_framework.md` is implicitly written for ~250–1000 MWe utility-scale steam. Applying it to a 50 MWe machine is a category-fit error, not a standardization win.
  3. **`scoring_framework.md` lines 325–331 ("Justified deviations") explicitly permit this case**: a concept "may use a non-canonical η_th if the underlying physics forces derating". Small-turbine off-design losses are exactly such a derating force (well-published in industrial steam-turbine literature; e.g., GE/Siemens product brochures for 30–80 MWe class). The 0.30 value was eligible for the carve-out and the standardization should not have been applied.
  4. **LCOE consequence:** at 50 MWe net and a small machine where capital efficiency is already poor, a 5 pp eta_th overstatement reduces required thermal power by ~17% and proportionally understates the chamber, blanket, and primary-loop sizing. For 34-india this is a non-trivial bias since the whole concept is a scale-penalty story (the docstring explicitly calls out scale penalty as the defining challenge).
- **Recommendation:**
  1. Revert `eta_th` to 0.30 with an inline comment of the form: `# DEVIATION (justified): scoring_framework.md §"Justified deviations" — small-plant derating. Canonical 0.35 is utility-scale (~250+ MWe) implicit; 50 MWe industrial steam turbines lose 3–7 pp from off-design effects (single-extraction reheat, reduced HRSG complexity). Cite: industrial steam-turbine 30–80 MWe class performance literature (GE/Siemens brochures or equivalent).`
  2. Source the small-plant derating quantitatively. Acceptable sources: any major-vendor 30–80 MWe steam turbine product datasheet, IEA/NREL small-cogeneration efficiency studies, or peer-reviewed industrial steam-cycle literature. If no specific number is sourced, label the deviation `UNCERTAIN: ±2 pp` and run a sensitivity sweep over eta_th ∈ {0.28, 0.30, 0.32, 0.35}.
  3. Reconcile the file: update the docstring (lines 17–19) and the print block (line 273) so all three locations agree on the modeled value. Currently the docstring/print say 0.30 but the kwarg says 0.35 — silent disagreement is a maintainability hazard.
  4. Add a brief note in Section 2 of `analysis.md` framing this as a recurring pattern: any concept below ~100 MWe net carries an implicit small-plant penalty that the per-category canonicals do not capture. This is methodologically the same point the broader audit (`.project/research/20260517-081444_model-setup-inconsistencies.md` §7) made about 34-india's parasitic-load eyeballing — both stem from missing a small-plant scaling framework.
- **Priority:** important
