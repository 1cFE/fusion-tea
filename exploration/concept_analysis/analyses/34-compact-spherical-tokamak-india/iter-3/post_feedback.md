### F-1: Physics uncertainty scenario produces misleadingly narrow LCOE range
- **Target:** Model F3 scenario and sensitivity table
- **Category:** model
- **Finding:** The analysis identifies "unknown machine parameters" as the second most Critical LCOE challenge (Goal 5), yet plasma physics parameters (B, T_e, n_e, tau_ratio, plasma_volume, q95) all show exactly 0.0 elasticity in the sensitivity table — they are not wired into cost calculations. The F3 geometry proxy (varying R0 ±15%) produces an LCOE range of only $613–$643/MWh (±2%), grossly understating the uncertainty for a concept with no published commercial design parameters. A commercial ST needing B_T = 2 T vs. 5 T to reach Q_eng > 1 has radically different magnet capital and recirculating power profiles — far more than a ±2% LCOE swing. The model cannot test the hypothesis it is most important to test, and the narrow F3 range creates a false impression of precision for an openly opaque concept.
- **Recommendation:** Replace the geometry-proxy F3 with scenario-based design points drawn from plausible commercial ST parameter ranges. Define Low/Base/High scenarios using (e.g.) B_T = 2 T / 3.5 T / 5 T with corresponding fusion power estimates, magnet capital scaling, and recirculating power fractions. Even if all values are analogues, computing LCOE for each scenario makes the true uncertainty range explicit. The Wide scenario LCOE range should span at least a factor of 2–3 given the data void acknowledged in analysis.md §1, rather than the current ±2%.
- **Priority:** blocking

### F-2: Only one nearest neighbor named; second comparator absent from concept positioning
- **Target:** Analysis header and Section 7 (Cross-Concept Notes)
- **Category:** analysis
- **Finding:** The analysis names only 21-spherical-tokamak-hts as the nearest neighbor. The checklist requires 2–3 named nearest-neighbor concepts for comparison (Goals 1–2). The frontmatter `Reuses` field already includes 01-hts-compact-tokamak (CFS), but it appears only as a sources reference in Sections 7–8, not as an explicit second comparator in the concept positioning. The omission matters: a reader cannot distinguish what is specifically *spherical* (low aspect ratio, center-stack geometry, high-beta operation) from what is generically *compact-HTS-tokamak* without the ST vs. conventional-compact comparison stated directly. The differentiators attributed to Pranos vs. Tokamak Energy in Section 7 are partly ST-vs-conventional-tokamak differences that would appear in a comparison with 01 as well.
- **Recommendation:** Name 01-hts-compact-tokamak as an explicit second nearest neighbor in the analysis header. In Section 7, add a concise "vs. 01-hts-compact-tokamak" comparison alongside the existing Tokamak Energy divergences list. Key axes: aspect ratio (ST A≈2 vs. conventional A≈3–4) → center-stack geometry constraint applies only to ST; higher beta in ST reduces magnet cost per MW but introduces different stability challenges; and scale (CFS targets GW-class, not 50 MW modular). This separates what is ST-specific from what is shared across compact-HTS-tokamak concepts.
- **Priority:** important

### F-3: H2 factory learning sweep does not answer the stated hypothesis
- **Target:** Model H2 scenario; Section 2 hypothesis H2
- **Category:** model
- **Finding:** Section 2 states H2 is testable by "sweeping the learning curve exponent from 0 (no learning) to 0.25 (aggressive learning) and identifying the break-even exponent at which LCOE reaches $100–$150/MWh." The model output shows only three fixed points (FOAK, mid-fleet, NOAK) with a fixed b≈0.15–0.20. The break-even exponent is not identified. More importantly, the 1 GWe reference scenario already reaches $84/MWh, making it clear that scale dominates over learning — but this interaction is not explored. The model concludes "factory learning alone cannot close the gap" without quantifying what combination of scale and learning rate would. The hypothesis as stated asks a specific quantitative question; the model gives a narrative answer without sweeping the relevant parameter space.
- **Recommendation:** Implement a sweep of Wright's Law exponent b over [0, 0.10, 0.15, 0.20, 0.25] and report NOAK LCOE for each. Since the 1 GWe reference achieves $84/MWh without any learning, add a combined axis: for each b value and for module sizes of 50 MW / 150 MW / 500 MW, identify which (scale, b) combinations bring LCOE below $150/MWh. This answers whether H2 is economically viable in any plausible scenario or categorically infeasible at 50 MWe — a key conclusion for the modular-fleet economic thesis.
- **Priority:** important
