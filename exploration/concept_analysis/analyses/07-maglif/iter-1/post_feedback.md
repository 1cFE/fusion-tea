### F-1: Driver-count contradiction — override applies single-driver cost to a 10-independent-driver plant
- **Target:** Section 5b (Override Candidates), C220107 rationale; and model_setup.py overrides list rationale
- **Category:** analysis
- **Finding:** Section 5 parameter table states the plant configuration is "10 chambers, each with independent driver, heat transfer, and power conversion" (sourced from z-ife-sand2006-7148-thermal-cycles.md §3.1.1.3). The C220107 override rationale contradicts this, claiming "the 10-chamber baseline uses one driver shared across chambers (via staggered firing), so this is a single capital item." The override applies $372M × 1.57 = $584M as the total plant driver cost. If each of the 10 chambers has an independent driver, the total driver capital is either 10× this figure (if each chamber needs a full 1 PW driver) or some intermediate value (if each chamber uses a smaller driver scaled to 0.1 Hz operation and lower per-chamber stored energy of ~20 MJ vs. 42 MJ for the optimized 1-chamber case). The model output shows C220107 = 584.0 $/kW (native), which implies $584M total — plausible for a single driver but potentially an order-of-magnitude undercount for 10 independent drivers. This is the dominant cost account and the only override; getting the multiplicity right is essential.
- **Recommendation:** Return to z-ife-sand2006-7148-thermal-cycles.md §3.1.2 and §3.1.1.3 to resolve whether the $372M estimate covers one driver or the entire plant's pulsed-power system. If it covers one driver for a 1-chamber plant, either (a) apply driver cost scaling (C_tot = 372 × (TW/1000)^0.6, as cited in the analysis) to the actual per-chamber driver power level and multiply by 10, or (b) adopt the optimized 1-chamber 0.5 Hz design point instead and adjust P_native accordingly. Update both the parameter table and the override rationale to be internally consistent on driver multiplicity.
- **Priority:** blocking
