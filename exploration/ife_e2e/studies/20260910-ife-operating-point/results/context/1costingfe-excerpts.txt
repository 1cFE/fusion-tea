608:     Unified pulsed-confinement balance using per-pulse energy parameters
609:     (e_driver_mj, f_rep) and a radiation loss fraction (f_rad).  Supports
610:     partial charged-particle direct capture via f_dec (default 0 = all ash
611:     thermalises) and eta_de (DEC efficiency).  Mirrors the steady-state
612:     hybrid formula: fraction f_dec of non-radiated ash is collected at
613:     eta_de, remaining ash and all radiation thermalise into the blanket.
614: 
615:     CRITICAL: All conditionals on float parameters use jnp.where because
616:     these parameters may be JAX tracers during sensitivity analysis.
617:     """
618:     # Average driver power
619:     p_driver = e_driver_mj * f_rep
620: 
621:     # Step 1: Ash/neutron split
622:     p_ash, p_neutron = ash_neutron_split(
623:         p_fus,
624:         fuel,
625:         dd_f_T,
626:         dd_f_He3,
627:         dhe3_dd_frac,
628:         dhe3_f_T,
629:         dhe3_f_He3,
630:         pb11_f_alpha_n,
631:         pb11_f_p_n,
632:     )
633: 
634:     # Step 2: Radiation and charged-particle split
635:     p_rad = f_rad * p_ash
636:     p_charged_net = p_ash - p_rad
637: 
638:     # Step 3: Direct charged-particle capture (hybrid mode; f_dec=0 means pure thermal)
639:     p_direct = f_dec * p_charged_net
640:     p_dee = eta_de * p_direct
641:     p_dec_waste = (1.0 - eta_de) * p_direct  # lost; not added to thermal
642: 
643:     # Step 4: Thermal power — (1-f_dec) of non-radiated ash + all radiation +
644:     # driver + pump thermalise. Pump only when thermal conversion is active.
645:     p_thermal_ash = (1.0 - f_dec) * p_charged_net + p_rad
646:     pump_term = jnp.where(eta_th > 0, p_pump, 0.0)
647:     p_th = mn * p_neutron + p_thermal_ash + p_driver + pump_term
648: 
649:     # Step 5: Thermal electric and gross
650:     p_the = eta_th * p_th
651:     p_et = p_the + p_dee
652: 
653:     # Step 6: Wall load from charged particles
654:     p_wall = p_charged_net
655: 
656:     # Step 7: Lost power
657:     p_loss = p_th - p_the
658: 
659:     # Step 8: Subsystem power
660:     p_sub = f_sub * p_et
661: 
662:     # Step 9: Scientific Q
663:     q_sci = p_fus / p_driver
664: 
665:     # Step 10: Recirculating and engineering Q
666:     p_aux = p_trit + p_house
667:     recirculating = (
668:         p_driver / eta_pin
669:         + jnp.where(eta_th > 0, p_pump, 0.0)
670:         + p_sub
671:         + p_aux
672:         + p_cryo
673:         + p_target
674:         + p_coils
675:     )
676:     q_eng = p_et / recirculating
677: 
678:     # Step 11: Net electric
679:     rec_frac = 1.0 / q_eng
680:     p_net = (1.0 - rec_frac) * p_et
681: 
682:     # Pulsed-specific fields
683:     e_stored_mj = e_driver_mj / eta_pin
684:     f_ch = _charged_particle_fraction(
685:         fuel,
686:         dd_f_T,
687:         dd_f_He3,
688:         dhe3_dd_frac,
689:         dhe3_f_T,
690:         dhe3_f_He3,
691:         pb11_f_alpha_n,
692:         pb11_f_p_n,
693:     )
694:
