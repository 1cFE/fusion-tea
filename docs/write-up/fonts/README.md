# Write-up fonts

Manrope and Fira Code, the fonts of the HTML write-ups. Pages load them from Google Fonts through `../write-up.css`. These copies let figure scripts draw with the same fonts, so figure text matches the page. Use them through `../figure_style.py`: `use_matplotlib()` for matplotlib and `graphviz_env()` for graphviz.

Downloaded from Google Fonts on 2026-09-26: Manrope Regular, Medium and SemiBold; Fira Code Regular and Medium. Both are licensed under the SIL Open Font License 1.1; see `OFL-Manrope.txt` and `OFL-FiraCode.txt`.
