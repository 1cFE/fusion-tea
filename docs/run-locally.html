Run the Fusion Concept Score Explorer locally

The complete tool can run from a downloaded directory. It needs no account, backend or paid service.

Download and run

Use a bundle from GitHub Releases when available, or download the repository's source. Extract it and run this command from the directory containing index.html:

python3 -m http.server 8000 --bind 127.0.0.1

Open http://127.0.0.1:8000/. Adjust the seven axis weights, filter the table, open a concept, or export the ranking. The tool works without external network access.

Use a fixed source revision

A generated release bundle includes release.json with the full source commit and its permanent GitHub URL. Check out that exact commit to reproduce the bundle. Do not substitute the latest branch if you need the same artifact.

git checkout <source_commit>
python3 tools/score_explorer/package_release.py --ref <source_commit> --output-dir /tmp/scoring-release

Verify the downloaded ZIP against its separate .sha256 file, then verify the extracted files with shasum -a 256 -c SHA256SUMS. Creating a local bundle does not publish a release.

Content and rights

The bundle preserves its captured scores and input weights. Changing axis weights recomputes the composite ranking in the browser. The source repository contains the separate Python workflow for regenerating individual scores.
