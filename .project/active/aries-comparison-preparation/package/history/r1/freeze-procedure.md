# Frozen comparison reproduction and post-reveal procedure

[AGENT] This package freezes preparation, not permission to reveal. The model is the unchanged WI-065 executable, with current-driven sizing selected in `input-rules.json`. Defaults, live loop/cycle/calendar, 1.0 inventory reserve, fourteen circuits and original cavity allocations are fixed. The readiness verdict and owner-held applicability decision are separate from arithmetic reproducibility.

## Reproduce the frozen preparation

[AGENT] `build_freeze.py` makes a deterministic archive with a SHA256 index over explicit model, generated package, study-route/oracle, reporting, tests, rule, acceptance and evidence files. The only holdout file included is its protocol. It excludes credentials, runtime import links/caches and unrelated untracked files. `freeze/<revision>/freeze-record.json` names the archive hash, base Git revision, count and index hash. The archive is the frozen byte set; a current working-tree file is not a substitute.

1. Verify the archive SHA256 against its freeze record, then run `.codex-test/run python .project/active/aries-comparison-preparation/package/build_freeze.py --verify <archive>`. This validates members, membership and every byte digest without extraction.
2. Restore into an isolated checkout of the recorded base revision and overlay the archive. From that checkout, run `sha256sum -c COMPARISON-SHA256SUMS`. All records retain repository-relative paths. The archive does not contain `.git`; source-history checks use the base checkout. External evidence cited by path/commit remains retrievable from that revision.
3. Use the sealed runtime described in `.project/codex-test-setup.md` and `docs/integration_seam_operator_guide.md`. The original launcher is checkout-specific: in a restored checkout, invoke the retained interpreter with the documented environment and that checkout on PYTHONPATH, without copying credentials. The sealed dependency identities are tested by `tests/test_dependency_provenance.py`; teax is revision `8d877460ac4f6f264561d916e40c1708adb13397`. SysIDE/teax licensing and the retained wheels are external prerequisites, not supplied by this archive. Do not replace them with whatever a package resolver currently installs.
4. Run the two comparison test files, the dependency-provenance test and the read-set-coverage test. Run `check_lineage.py --out <new-receipt>` and `check_accounting.py` in the restored checkout. The latter reproduces the retained evidence receipt without physical execution. Re-run the synthetic report command in `reporting.md` to a new path and require byte equality with `synthetic-report.json`.
5. `selected-mode/native-result.json` and its native SQLite/content-addressed artifact retain the one necessary model-side verification. `check_selected_mode.py` reproduces its oracle comparison without another native physical run. It must preserve the two near-zero-margin tolerance misses and nineteen-of-twenty oracle predicate agreement, with all twenty native-operand reconstructions agreeing. No additional physical run is needed just to re-export documents.

[AGENT] Two independently built archives from unchanged inputs must be byte-identical. A tampered extracted input must fail the SHA256 check. The freeze verification receipt records these checks. Changes after this freeze require a new identifier and cannot replace the original blind result.

## Execute after an owner-triggered reveal

1. **Owner gate first.** Resolve the named comparison-scope decision and obtain the owner's explicit reveal under the quarantine protocol. An unresolved essential applicability decision prevents a readiness claim. Any changed scientific model or formal comparison meaning needs a new pre-reveal preparation freeze; approval does not make missing quantities pass.
2. **Extract without selecting for fit.** Preserve source transcriptions and conflicts in the protocol's comparison/extracted locations. Apply `input-applicability.md` source priority and exact definitions. Record raw units, basis, account scope, revision, uncertainty and page/table. Select only the seven permitted independent keys; if a key is missing, retain the held fallback visibly and block dependent fixed-point applicability. Do not derive an input from a desired output.
3. **Run the frozen forward case first.** Prepare a JSON request with `run_kind: "blind"` and `values` keyed by allowed full input names. Each supplied item has exactly `value`, `unit`, `source`, `definition` and `resolution: "matched"`; use the frozen key's unit after an explicitly recorded permitted conversion. Run `execute_frozen.py --request <request.json> --out-dir <new-comparison-directory>`. The adapter rejects unlisted overrides and retains all native outputs, twenty verdicts, selected modes, supplied keys, held fallbacks and execution failures. It refuses to reuse an existing output directory.
4. **Map values without filling gaps.** Run `export_model_values.py --manifest <manifest.json> --native-result <new-comparison-directory>/native-result.json --out <model-values.json>`. This maps every row, including the three structural evidence rows and five absent producers. Predicate values use 1/0 only as a display of the separately retained native verdicts. Supplied-input aliases must be classified through their declared input source. Review the complete producer mapping; no missing output becomes zero.
5. **Assemble and check the comparison.** Build the reporter's observation schema from these mapped values and retained reference transcription, following `reporting.md`. Its synthetic fixture is a schema example only: never copy its artificial values or evidence assertions. Include every formal row, the exact twenty constraints, applicable extrapolation flags, model validity and source-supported scope/technology correspondence. A missing independent input, unresolved source conflict, unsupported technology or essential scope decision must remain unresolved in dependent rows; a nonempty evidence string cannot scientifically resolve it. Peer review this evidence mapping before accepting any verdict. Raw/published values survive every allowed conversion.
6. **Publish the original result.** Run the frozen reporter and publish its per-row and per-axis verdicts, raw/adjusted values, model/reference ratios, C220107 disclosures, accounting residuals, constraints and missing/applicability outcomes. Preserve this first report immutably. A process exit of zero means the reporter ran, not that the comparison passed. LCOE has no formal acceptance band. The original [1/3,3] and [0.5,2] endpoints stay fixed.
7. **Keep later work separate.** A conditioned request uses `run_kind: "conditioned"`, one named `conditioned_seam` and exactly its required `conditioned_values`, plus the same frozen blind inputs. It produces a different directory/report and earns no independent blind credit. Permitted seams are fixed in the rules. Post-reveal conversion amendments, corrections, alternate technologies and optimization are separately versioned diagnostics or new work; they cannot improve the frozen original retrospectively.

[AGENT] Structural correspondence and scientific applicability require evidence interpretation. Software validates declared structure and arithmetic; it cannot prove a reference citation supports the asserted equivalence. This limitation is why the source/input selection record and independent review remain part of the procedure.
