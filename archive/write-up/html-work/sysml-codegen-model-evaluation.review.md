The page does still read in full with scripts disabled — every live panel has a pre-rendered static value and the plan's "without scripts" fallback text is present (e.g. `#graph-static`, `#map-static`) — so the *reading experience* requirement is met, but the *script-scope* sentence as written is not. The page plan (`sysml-codegen-model-evaluation.page-plan.md`, "Interactive figures, for approval") frames this interactivity as "the owner's request for this page," so this may already be a known, accepted exception — but the render prompt text I was given doesn't record that exception, so the two documents disagree. Worth the coordinator confirming the exception is actually on record somewhere before treating this page as prompt-compliant. (cites: `html-render-prompt.md` § Hard constraints)

2. **One evidence-panel disclosure line is a double clause.** Every other evidence-panel summary on the page is a bare noun phrase ("What the fit calculation reads," "The 18 connections behind the graph," "The generated wrapper around it," "The pipeline around this entry," "The input files," "Input generation," "The three recorded cases," "Held inputs for the map," "What the specialized body adds," "How Python bodies survive regeneration"). The render prompt asks for disclosure summaries "like a heading: a bare noun phrase or one plain claim," and this is the pattern the shared feedback calls out directly. (cites: `html-render-prompt.md` § What the page adds; `html.md` "Dropdown summary line written as a double clause")
