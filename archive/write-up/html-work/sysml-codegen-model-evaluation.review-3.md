## Findings

1. The page's inline script does far more than track navigation state. Beyond the navigation-highlighting code (which matches the allowed pattern), the same `<script>` block (lines 13994–14271) drives four fully interactive widgets: a range-slider "Try it" panel that recomputes the field equation live (`#field-live`, line 479, §2.1); a clickable dependency-graph explorer that highlights upstream/downstream nodes (`#graph-live`, line 800, §2.3); a second range-slider panel for the breeding surrogate (`#breeding-live`, line 1235, §2.4.1); and a hoverable/arrow-key-navigable 256-point map with a checkbox that recolors marks by failing check (`#map-live`, line 13861, §2.7.2). The writer prompt's hard constraint states: "An inline script may only track navigation state, as the style sample's script does" (html-render-prompt.md, Hard constraints, line 42). The script's own comment (line 13995) says these four figures are "the four figures the owner approved for scripting," but no document named in this review's brief records that approval, so as written the page fails the stated constraint. (cites: html-render-prompt.md, Hard constraints)

2. The §2.5 code block is reordered and has a fourth, unsourced declaration added. The markdown's single fenced SysML block (sysml-codegen-model-evaluation.md, lines 187–202) holds exactly three declarations in this order: the generic-plant usage, the specialized definition, then the stellarator redefinition. The page's "Three declarations, three files" diagram (HTML lines 1299–1352, §2.5) presents the specialized definition before the generic-plant usage (reordering the pair), and prepends a fourth code excerpt — `part def 'Blanket' :> 'CAS22 Power Core' { attribute tbr : Real default 1.0; // ... }` — that does not appear anywhere in the markdown; its own label reads "not in the code block." The writer prompt permits only specific adaptations to carried content (drop scaffolding, anchor ids, link-to-path conversions, section-reference links) and allows new visuals only when "built only from facts the markdown states or its linked evidence records" (html-render-prompt.md, "Keep the prose" and "New visuals" sections); this fourth declaration cannot be checked against anything named in the markdown or its cited evidence files. (cites: html-render-prompt.md, "Keep the prose" / "New visuals, only where they help")

(cites: synthesis.md, "Clause the reader already has")
