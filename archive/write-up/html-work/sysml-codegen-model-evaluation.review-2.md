## Findings

1. **The inline script does far more than track navigation state.** The hard constraints say "An inline script may only track navigation state, as the style sample's script does" (html-render-prompt.md, Hard constraints). The page's `<script>` block (lines 13994-14269) runs four separate interactive subsystems: a slider pair that recomputes the axis-field equation live (`mu0 * kLink * nCoils * i * 1e6 / (twoPi * r)`, lines 14027-14044, Figure 2); a click-driven dependency explorer over the calculation graph that walks upstream/downstream closures and rewrites a readout panel (lines 14047-14129, Figure 4); a thickness slider that re-runs the breeding-surrogate interpolation and rewrites its result sentence (lines 14132-14176, Figure 5); and a 256-case map explorer with hover/click selection, grid-stepping arrow buttons, and a check-based recoloring toggle (lines 14180-14268, Figure 8). This is computation and data filtering, not navigation state. The script's own comment ("the four figures the owner approved for scripting," line 13995) implies an out-of-band exception, but that exception is not written into the render prompt I was given — worth the coordinator confirming whether the instructions are stale or the page overstepped them.

2. **Two of the five markdown figures lose their alt-text sentence entirely.** The render prompt requires: "Keep the markdown's alt text and caption" (html-render-prompt.md, Figures). Figures rebuilt as a single inline `<svg>` do this correctly — Figure 4's `aria-label` (line 626) and Figure 8's `aria-label` (lines 1727, 7838) both reproduce the markdown's alt text verbatim. But two figures rebuilt as HTML/CSS box-and-arrow diagrams carry no equivalent anywhere on the page:
   - Figure 2 (`sysml-codegen-assets/stellarator-component.png`, lines 415-471): the alt text "Plant values and the shared plasma radius feed the coil attributes; field_calc binds those inputs to the Coil Set Axis Field equation, and the magnet exposes the computed B_axis as B." does not appear on the page in any form.
   - Figure 7 (`sysml-codegen-assets/stellarator-magnet-tradeoff.png`, lines 1578-1691): the alt text "Three recorded stellarator cases: current sizing raises cost and fixes current capacity; enlarged space fixes fit but violates the field limit." does not appear; the only `aria-label`s nearby are per-card SVG drawings with unrelated, narrower descriptions.

3. **Several collapsed evidence panels add substantive new facts that are not in the markdown and go beyond showing what a cited reference contains.** The render prompt scopes the writer's job to "the reading experience and the visual layer, not a new explanation," and says any other change belongs in the report as a proposal, not on the page: "Do not make the change. The coordinator takes it to the owner" (html-render-prompt.md, opening paragraph and "Keep the prose"). Four panels cross that line — none of these numbers or claims are stated anywhere in the markdown, and they read as findings from the render agent's own inspection of current files rather than a display of "what the file points to":

   - Line 1524 (panel "In the package / The input files", under 2.6.2): "eight calculations read `plasma__R` directly: ... Seven read `coil__I_coil`: ..." — a concrete enumeration not given in the markdown.
   - Line 1712 (panel "In the record / The three recorded cases", under 2.7.1): "The study's report records the reference divertor load as 10.52 MW/m² against a 10.0 MW/m² limit, and notes that its priced subtotals carry mixed price bases and unresolved manufacturing scope, so they are conditional estimates, not procurement quotations."

   All four sit inside closed `<details class="evidence">` panels rather than the main flow, which limits how many readers see them, but they are still new explanatory content rather than adaptation.
