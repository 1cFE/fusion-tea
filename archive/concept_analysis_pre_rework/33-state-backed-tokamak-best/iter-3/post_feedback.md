### F-1: Q sweep does not capture recirculating power cliff-edge
- **Target:** `model_setup.py` — Q sensitivity sweep
- **Category:** model
- **Finding:** The Q sweep holds p_fus fixed at 3673 MW and reports p_net = 1000 MW at every Q value, which is physically inconsistent at low Q. At Q = 5, H&CD electrical demand ≈ p_fus/(Q × η_pin) = 3673/(5 × 0.60) = 1224 MWe, against gross electrical output ≈ 3673 × 0.347 = 1274 MWe — leaving only ~50 MWe net, not 1000 MWe. As a result, LCOE varies only from 193.8 to 161.3 $/MWh over Q = 5–15 (a 20% slope), when the analysis explicitly states the sweep should "reveal the cliff-edge in net electrical output as recirculating H&CD power approaches gross generation at low Q." The thermal breakeven Q for this efficiency combination (η_th = 0.347, η_pin = 0.60) is Q_break = 1/(η_th × η_pin) ≈ 4.8; below this Q no net power is possible at any fusion power. The model shows no such structure. The Q sweep has high priority for this concept because CFETR Phase I targets Q ≈ 3.2 and commercial PFPP Q is unknown — this sensitivity directly tests whether the concept's commercial pathway is viable.
- **Recommendation:** Fix the Q sweep to correctly propagate recirculating power into net output. Two valid approaches: (a) at each Q, recompute p_fus to maintain p_net = 1000 MWe — this will show LCOE diverging sharply as Q approaches Q_break, and become infeasible below it; or (b) hold p_fus constant at the reference value and compute and display actual p_net = p_fus × η_th − p_fus/(Q × η_pin) − parasitic at each Q, showing p_net collapsing toward zero near Q_break. Report Q_break explicitly in the sweep output. The expected result is that LCOE increases sharply below Q ≈ 6–8 and the concept is unviable below Q ≈ 5.
- **Priority:** blocking

### F-3: Modeling framework choice not explicitly stated
- **Target:** Section 7 — Cross-Concept Notes / Modeling Approach
- **Category:** analysis
- **Finding:** The checklist requires the analysis to state whether 1costingfe or free-form modeling is appropriate and why. Section 7 provides a detailed list of modeling parameters, geometry analogs (ARIES-ACT1), and scenario branches, but never explicitly states which modeling framework is being used or why. The model output implicitly uses CAS-structured costingfe (via the ARIES-ACT1 geometry analog), but this choice is nowhere justified in the analysis text. For a concept that requires extrapolation across two device generations (BEST → CFEDR → PFPP), the choice between anchoring to a validated costingfe baseline (ARIES-ACT1 at matched geometry) versus free-form parametric modeling has real implications for how uncertainty is propagated. The justification — conventional AR D-T tokamak with well-characterized CAS cost structure from ARIES/PROCESS — is implicit but should be made explicit so a future analyst understands why the costingfe framework was applied rather than a free-form approach.
- **Recommendation:** Add one sentence in Section 7's "Cross-concept positioning for TEA pipeline" paragraph explicitly stating the framework choice: "The 1costingfe framework is appropriate for this concept because the commercial PFPP is a conventional-aspect-ratio D-T tokamak whose CAS cost structure is well-characterized by ARIES-ACT1 at matched geometry; free-form modeling is not warranted at this stage given that the PFPP design is unspecified and ARIES-ACT1 already brackets the parameter space with appropriate uncertainty." This makes the modeling approach auditable against the checklist without changing any computation.
- **Priority:** minor
