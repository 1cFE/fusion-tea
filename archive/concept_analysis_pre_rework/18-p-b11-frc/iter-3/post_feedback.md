### F-1: Section 7 LCOE anchoring is stale relative to iter-3 model outputs
- **Target:** Section 7 "Rough LCOE anchoring against D-T FRC reference" paragraph
- **Category:** analysis
- **Finding:** Section 7 anchors the concept's economic position against two specific reference points — Branch B at Q_plasma=15 → "~$250–270/MWh" and Branch C → "~$75–80/MWh" — both of which directly contradict the iter-3 model output. With the corrected η_NBI=0.26 two-step efficiency chain, Q=15 is Branch A (P_net=-1.4 MWe, no LCOE), and Branch C at Q=30 produces $44/MWh, not $75–80/MWh. The Helion comparison claim that Branch B is "6× worse than the best analogous D-T-free FRC estimate" and the conclusion that steam-mode p-B11 FRC "is not economically competitive" both rest on this stale $250/MWh Branch B anchor. The parenthetical note at the end of Section 7 references "CF-F-1" and "CF-F-2" correction items that have since been resolved. Section 7 was written against a prior model version (η_NBI≈0.55, source efficiency only) and was not updated after the two-step NBI correction was introduced.
- **Recommendation:** Update Section 7 LCOE anchoring to use iter-3 model values. The minimum commercially viable Branch B reference should be Q=20 ($298/MWh, the lowest-Q viable steam scenario in the model sweep) or Q=25 ($164/MWh, the stated commercial minimum). Update Branch C reference to $44/MWh. Revise the Helion comparison ratio accordingly — Branch B at Q=25 ($164/MWh) remains ~4× worse than the Helion D-He3 $40/MWh estimate, preserving the same qualitative conclusion. Remove the stale CF-F-1/CF-F-2 parenthetical.
- **Priority:** important

### F-2: Section 5 fusion power estimate breaks at corrected NBI efficiency; model baseline scale unexplained
- **Target:** Section 5 "Available Parameters" row "Fusion power required for 50 MWe (steam)"; Section 2 Challenge 3
- **Category:** analysis
- **Finding:** Section 5 estimates "~170–200 MWth" fusion power for 50 MWe Da Vinci, explicitly derived from η_th alone with f_recirc→0. At the corrected η_NBI=0.26, the NBI wall-plug load at the model baseline is ~100 MW (26 MW plasma / 0.26), which already exceeds the gross electricity from 170–200 MWth × 32% (~54–64 MWe gross). The estimate is therefore inconsistent with the corrected model by a factor of ~2: producing 50 MWe net at Q=30, η_NBI=0.26 actually requires ~350 MWth. Separately, the model baseline uses P_NBI_plasma=26 MW → P_fusion=780 MWth → 104.7 MWe net — roughly twice the stated Da Vinci 50 MWe specification — with no explanation of why this scale was chosen or how it relates to Da Vinci. Model sweep 6 shows P_NBI≈15 MW → 57 MWe net, which is closest to Da Vinci scale, but this is not called out as the relevant reference point.
- **Recommendation:** Update the Section 5 estimate to state: "~350 MWth at Q=30, η_NBI=0.26 (accounting for NBI recirculating load); see model sweep 6 for scale sensitivity." Add a note explaining that the model baseline (P_NBI=26 MW, P_fusion=780 MWth, P_net≈105 MWe) is a reference scale for illustrative purposes and is not calibrated to the 50 MWe Da Vinci specification — the Da Vinci-scale model equivalent is the P_NBI≈15 MW row in sweep 6 (~57 MWe net, $141/MWh Branch B).
- **Priority:** important

### F-3: f_rad=0.15 baseline is inconsistently optimistic for the concept's primary physics unknown
- **Target:** model_setup.py Branch B/C baseline f_rad parameter; scenario comparison table
- **Category:** model
- **Finding:** The model uses f_rad=0.15 as the central baseline, which implicitly assumes TAE's non-Maxwellian T_i>>T_e strategy is already ~85% effective at suppressing bremsstrahlung at Da Vinci conditions — a partial success of the very physical bet the analysis correctly identifies as "the primary unknown the concept is trying to solve" and "entirely unvalidated" at 150+ keV. A central case assumption should not presuppose substantial success of the concept's defining undemonstrated claim. The Q×f_rad viability grid (sweep 9) is excellent and shows the full range, but the headline branch baseline understates expected cost: Branch B at f_rad=0.15 → $119/MWh, f_rad=0.30 → $168/MWh, f_rad=0.50 → $545/MWh. The scenario comparison table has no row showing a pessimistic f_rad case, so the sensitivity is not visible in the primary summary.
- **Recommendation:** Change the Branch B/C model baseline from f_rad=0.15 to f_rad=0.30 (representing "partial, pessimistic but non-zero T_i>>T_e suppression — the defensible central case for an undemonstrated strategy"). Keep f_rad=0.15 as the "suppression substantially achieved" scenario, visible in the sensitivity sweep. Add a "B Pessimistic f_rad" row to the scenario comparison table at (Q=30, f_rad=0.50, η_NBI=0.26, CF=85%) → $545/MWh to make the viability boundary visible at the headline level. Add a note to the model output header explaining what physical assumption the baseline f_rad represents.
- **Priority:** important
