# AGENTS.md — Concept Explorer

## Build & Run

```bash
# Install dependencies
uv sync

# Extract data from pipeline artifacts (required before first run)
uv run python exploration/concept_explorer/extract_explorer_data.py

# Start server (primary mode)
uv run python exploration/concept_explorer/server.py
# → http://localhost:8421

# Extract specific concepts only
uv run python exploration/concept_explorer/extract_explorer_data.py --concept 01 04

# Skip LLM narrative extraction (faster dev iteration)
uv run python exploration/concept_explorer/extract_explorer_data.py --skip-narrative

## Validation

```bash
# Tests
uv run python -m pytest exploration/concept_explorer/

# Type checking
uv run mypy exploration/concept_explorer/

# Lint
uv run ruff check exploration/concept_explorer/
uv run ruff format --check exploration/concept_explorer/

These are backpressure. All three must pass before shipping.

## Codebase Patterns

**File layout** (all paths under `exploration/concept_explorer/`):
- `models.py` — Pydantic types only. No I/O, no imports from costingfe.
- `extract_explorer_data.py` — pipeline artifacts → `data/*.json`. Runs at build time.
- `server.py` — FastAPI server. Renders Jinja2 templates to `dist/` on startup.
- `templates/*.html.j2` — structural shells only, no embedded data.
- `static/js/*.js` — vanilla JS + Plotly. No bundler, no npm.
- `data/` — gitignored generated JSON. Must exist before server starts.

**Pydantic conventions:**
- All data between pipeline → server → frontend flows through typed Pydantic models.
- Use `model_validate_json()` / `model_dump_json()` — not `json.loads()` + raw dicts.
- `sensitivities: SensitivityAnalysis | None` — standalone concepts have `None`. Handle explicitly, never assume present.
- All monetary values: `cost_m_usd: float` (M$). No other unit.
- Elasticity is dimensionless: `(dLCOE/dp) * (p/LCOE)`.

**1costingfe integration:**
- Import: `from costingfe import CostModel, ConfinementConcept, Fuel`
- Build `CostModelData` from `ForwardResult` using `CostModelData.from_forward_result(result, sensitivities)`.
- `model.sensitivity()` returns `{"engineering": {param: elasticity}, "financial": {param: elasticity}}`.
- Use `dataclasses.asdict()` to serialize `ForwardResult` — no `.to_dict()` exists.

**FastAPI conventions:**
- All `/api/*` routes return typed Pydantic models directly (FastAPI serializes them).
- 404 for missing concept/parameter, 422 for standalone concept on `/api/compute`.
- `ExplorerState` updated via `POST /api/state`; frontend pushes on every navigation and slider change.

**JS conventions:**
- Each chart is a standalone function: `renderTornado(container, options)`, `renderCASBreakdown(container, options)`.
- All data fetched at runtime via API — no data embedded in HTML.
- Fetch concept data and manifest in parallel with `Promise.all()`.
- Debounce slider → `/api/compute` calls at 200ms.

## Known Gotchas

- **`uv run` always** — never `python`, `python3`, or `pip` directly.
- **`data/` must be populated** before `server.py` starts. If the server returns 404s for all concepts, run `extract_explorer_data.py` first.
- **Standalone concepts** (`02-acoustic-icf-sonofusion`, `12-levitated-dipole`) have `sensitivities=None` and `model_type != "costingfe"`. The frontend must show the no-sensitivity placeholder — never render an empty tornado chart.
- **`POST /api/compute` returns 422** for standalone concepts — this is correct behavior, not a bug.
- **Sensitivity is NOT recomputed on slider changes** — `/api/compute` response includes pre-computed baseline sensitivities. Don't call `model.sensitivity()` in the compute handler.
- **`cas22_detail` keys are strings** like `"C220101"` — not ints. Normalize with `str(code)` when mapping from `ForwardResult.cas22_detail`.
- **`model_validator` on `ConceptData`** warns if `parameter_metadata` doesn't cover all sensitivity keys. This is a warning, not an error — extraction proceeds.
- **Jinja2 templates are shells** — template variables are limited to page identity (e.g., `{{ concept_id }}`). Never embed cost data in templates.
- **`dist/` is gitignored** — it's generated by the server on startup. Don't commit it; don't assume it exists before the server runs once.
- **Population whiskers on tornado chart** require the manifest (cross-concept elasticity range). Fetch manifest in parallel with concept data on page load.
